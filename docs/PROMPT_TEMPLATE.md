# AI prompt template

Use this template when updating the website content or structure.

## Task
Describe the change you want to make.

## Scope
- Which page or route should be updated?
- Which content section should change?
- Which business message should be preserved?

## Constraints
- Keep the site as a multi-page company website.
- Preserve the company profile and business terminology.
- Keep content in structured data where appropriate.
- Do not replace the routing architecture unless explicitly requested.

## Expected output
- Updated content in the correct source file.
- Any necessary route or component changes.
- A brief explanation of the changes.
